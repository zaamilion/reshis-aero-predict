# Использование инструментов ИИ при разработке

В соответствии с правилами кейс-чемпионата (Использование ИИ разрешено «с умом»), при разработке данного продукта применялись технологии искусственного интеллекта.

**Использованная модель:** Gemini 3.1 Pro (Google)

**Как применялся ИИ:**
1. **Генерация бойлерплейт-кода:** ИИ использовался для создания базовой структуры FastAPI-приложения (схемы Pydantic, конфигурации базы данных SQLite, настройки маршрутизаторов).
2. **Контейнеризация:** Написание `Dockerfile` (включая multi-stage сборку для фронтенда на Nginx) и конфигурации `docker-compose.yml` для быстрого развертывания.
3. **Разработка UI:** Создание адаптивной верстки компонентов React с использованием Tailwind CSS и помощь в настройке графиков `Recharts`.
4. **Ревью и отладка:** ИИ выступал в роли "парного программиста" для быстрого поиска синтаксических ошибок (например, разрешение конфликта версий библиотеки `bcrypt` и `passlib`) и оптимизации импортов в TypeScript.

**Самостоятельная работа:**
Перенос бизнес-логики и математических формул из технического задания (расчет квантилей, применение коэффициентов `price_sensitivity`, ограничение продаж по `seats`), архитектурное проектирование REST API и тестирование продукта проводились самостоятельно. ИИ не использовался для решения аналитической части задачи за участника, а выступал исключительно как инструмент разработки программной оболочки.
