# ✈️ Решись Авиа — Платформа динамического ценообразования

Полноценное веб-приложение для аналитиков авиакомпании «Решись Авиа». Позволяет прогнозировать спрос на авиабилеты в зависимости от назначаемой цены, рассчитывать медианные продажи и визуализировать квантили вероятностей на интерактивном графике. 

Решение разработано в рамках кейс-чемпионата (Задача продвинутого уровня). Вариант реализации: **С (Веб-страница с backend-составляющей)**.

## 🛠 Стек технологий
* **Backend:** Python 3.11, FastAPI, SQLAlchemy, SQLite, Pandas, JWT (bcrypt).
* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS (v4), Recharts.
* **Инфраструктура:** Docker, Docker Compose, Nginx.

## 🚀 Как запустить проект (через Docker)

Убедитесь, что у вас установлен Docker и Docker Compose.

1. Склонируйте репозиторий (или скачайте ZIP-архив).
2. Поместите файлы данных `seasonal_forecast.csv` и `routes.csv` в папку `backend/data/`.
3. В корневой папке проекта выполните команду:
   ```bash
   docker-compose up -d --build
   ```
4. Приложение готово к использованию!
   * **Frontend (Дашборд):** Откройте в браузере `http://localhost` (или IP вашего хостинга).
   * **Backend API (Swagger UI):** Доступно по адресу `http://localhost:8000/docs`.

## ✨ Реализованный функционал
* **Обязательные функции:** Расчет спроса с учетом эластичности по цене и лимита вместимости (`seats`).
* **Доп. Функция 1:** Интерактивный график распределения спроса (сценарии 0.1 - 0.9) с отображением лимита мест.
* **Доп. Функция 2 и 3:** Регистрация и JWT-авторизация пользователей.
* **Доп. Функция 4:** Полная Docker-контейнеризация для размещения на VPS-хостинге.
