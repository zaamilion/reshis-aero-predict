# ✈️ Решись Авиа — Платформа динамического ценообразования

Полноценное веб-приложение для аналитиков авиакомпании «Решись Авиа». Позволяет прогнозировать спрос на авиабилеты в зависимости от назначаемой цены, рассчитывать медианные продажи и визуализировать квантили вероятностей на интерактивном графике. 

Решение разработано в рамках турнира «Решись» (Задача продвинутого уровня). 
Спроектировал и разработал решение участник турнира Жарков Артём Алексеевич.

Вариант реализации: **С (Веб-страница с backend-составляющей)**.

## 🛠 Стек технологий
* **Backend:** Python 3.11, FastAPI, SQLAlchemy, SQLite, Pandas, JWT (bcrypt)
* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS (v4), Recharts
* **Инфраструктура:** Docker, Nginx

## 🚀 Как запустить проект (через Docker)

Убедитесь, что у вас установлен Docker и Docker Compose.

1. Склонируйте репозиторий (или скачайте ZIP-архив).
2. В корневой папке проекта выполните команду:
   ```bash
   docker-compose up -d --build
   ```
3. Приложение готово к использованию!
   * **Frontend:** `http://localhost`
   * **Backend API:** `http://localhost/api`
   * **Backen(Swagger UI):** `http://localhost:8000/docs`

## ✨ Реализованный функционал
* **Обязательные функции:** Расчет спроса с учетом эластичности по цене и лимита вместимости (`seats`).
* **Доп. Функция 1:** Интерактивный график распределения спроса (сценарии 0.1 - 0.9) с отображением лимита мест.
* **Доп. Функция 2 и 3:** Регистрация и JWT-авторизация пользователей.
* **Также реализовано:** Полная Docker-контейнеризация для размещения на VPS-хостинге.

## Использование ИИ

В соответствии с правилами турнира (Использование ИИ разрешено «с умом»), при разработке данного продукта применялись технологии искусственного интеллекта.

**Использованная модель:** Gemini 3.1 Pro (Google)

Нейронка писала в большей степени бойлерплейт-код. Это базовые структуры, схемы, делал красоту фронтенду. Архитектурное проектирование REST API и тестирование продукта проводились самостоятельно. ИИ выступал исключительно как инструмент разработки программной оболочки.

**От создателя:** Лично мне очень нравится направление разработки, где человек принимает ключевые решения в проектировании и создании продукта, будь то задание правил архитектуры и подробное ее описание, ИИ в таком случае становится лишь исполнителем, но и частично справочником. Это наделяет человека, разбирающегося в том, какую систему он делает, большими возможностями в сфере разнообразия кода. Это и происходит с frontend'ом, нейронка пишет его отлично и очень красиво, оставляя человеку задать правила API, функционала и т.д.
НО ТАКЖЕ это не становится полноценным вайбкодингом лишенным души, где человек просто нажимает старт, ничего сам не делает и не может ответить за любую функцию.
